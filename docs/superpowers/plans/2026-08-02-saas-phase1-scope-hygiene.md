# SaaS Phase 1: Scope Hygiene Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Land Phase 1 of the on-prem/SaaS split ADR: no core package hardcodes the `"local-team"` scope, handlers resolve scope from the authenticated principal, the ~1300-line root `main.go` wiring moves to `internal/app` with a `cmd/team-memory-onprem` entrypoint, and a depguard rule locks the core→deployment dependency direction.

**Architecture:** Pure refactor with zero behavior change for the on-prem distribution (per `docs/decisions/2026-07-31-onprem-saas-split.md`, Phase 1). Scope literals survive only in the deployment adapter (`internal/deployment/onprem`) and the wiring layer (`cmd/*`, `internal/app`). `HumanPrincipal` gains a `ScopeID` field stamped by `IdentityService`, which is the seam Phase 3 later flips to per-team resolution.

**Tech Stack:** Go 1.25, Hertz (route glue generated by hz v0.9.7), pgx/pgxpool, testify suites, golangci-lint v2.
